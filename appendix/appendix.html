Scope and responsibility

  • All numerical results reported on the poster were produced by executing the code in the repository against local language models. No result, table or figure value was written or estimated by a generative model.
  • The experimental design, the research question and the three hypotheses were set by the author before implementation.
  • Every bibliographic entry in Section A was verified by the author against the source record; none was accepted on the assistant's assertion alone.
  • The author has read, checked and proofread the whole submission and takes full responsibility for its content, including any passages produced with assistance from the tool named above.

Reproducibility

The repository contains the complete environment, all generated agent traces, all 606 judge outputs, the analysis code and the figure scripts, so that every number on the poster can be recomputed from the committed data. The full development history, including the assistant's contributions, is visible in the commit log.
